# 共有の買取記録を接続する

保存先は指定済みです：
https://docs.google.com/spreadsheets/d/1KHm_HDKALE-og1rnqxuaCfW6K6Mu_skTORW3zOZ5fCg/edit

1. 上のシートで「拡張機能 → Apps Script」を開きます。
2. `コード.gs` を、このフォルダの **Code.gs** の全文で置き換えて保存します。
3. 左の「＋ → HTML」を選び、名前を **Panel** にします。内容を **Panel.html** の全文で置き換えて保存します。
4. 上部の実行する関数で **setup_** を選び、実行します。初回のGoogleの権限確認を進めてください。「買取ログ」タブが作られます。他のタブは消しません。
5. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」を選びます。
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**（Googleログインなしで使う設定）
6. デプロイして、表示された **ウェブアプリURL（末尾 /exec）** をチャットに送ってください。サイト全員共通の接続先に反映します。

シート自体の共有権限を「全員が編集可能」にする必要はありません。シート所有者として動くGASが「買取ログ」へ追記します。利用者はサイトから枚数を追加・訂正できます。

## 使い方

- サイトでカードを選び、「このカードの買取枚数を入力」を押します。
- PSA8・9・10と枚数を選び、「買取枚数を追加」で記録します。
- 入力ミスは「枚数を減らす」で訂正します。記録済み枚数未満にはできません。
- 全員の画面を15秒ごとに更新します。過去日は日付欄で選んで閲覧できます。
- 「この日のPDFを作成 → PDFを保存」で、日付・カード名・型番・収録弾・PSA・枚数・合計枚数のPDFを保存できます。
- 未確認の送信がある場合は「再確認」を使います。同じ操作IDで確認するため二重加算しません。未確認のままタブを閉じず、保存を確認してください。

日付はサーバー側の日本時間です。0時をまたいだ新規入力は確認メッセージを表示します。各操作を追記方式で保存し、同時入力はGASのロックで直列に処理します。`買取ログ` の列順や操作IDを手動で変えないでください。

## 動作確認の範囲

ローカルテストで再送・同時更新用ロック・グレード別集計・減算・日跨ぎ・不正入力の拒否を確認しています。Google上での接続、匿名アクセス、日本語PDFの表示と保存は、デプロイ後に確認します。PDF変換にはApps Scriptの利用上限があります。

更新時はGASの保存だけでなく「デプロイを管理 → 編集 → 新しいバージョン」で反映します。同じデプロイのURLを維持してください。
