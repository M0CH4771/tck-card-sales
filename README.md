# トレカ成約価格検索

日本語版の発売済み **AR 547種類・CHR 58種類（計605種類、38収録弾、2026年9月10日時点）** を検索できます。初期表示はPSA8、AR・CHR両方です。ALTで確認した成約履歴をカード・鑑定グレードごとに紐付けます。

## カード一覧と価格の範囲

`dist/catalog.json` は発売済みカードの一覧、`dist/data.json` は実際に確認した取引履歴です。カード一覧にある全種類を表示し、未取得・公開履歴なしも検索に残します。取引履歴のない価格を0円に置き換えません。成約履歴を確認できるカード数、確認済みカード数、各PSAグレードの確認日時を画面に表示します。

対象は日本語版でレアリティがARまたはCHRのカードです。SAR・CSR・海外版・AR/CHR表記のないプロモ・未発売カードは含めません。新しい収録弾は発売と全種類の番号・名前を確認して追加します。

カード名・番号・収録弾は以下の一覧を基に、TCGdexの公開カードデータ604件と照合しました。TCGdex側で未収録だったワンパチ M2/086 はALTの商品表示でも確認しています。日本語名の表記違いは照合時に修正しました。

- AR：[MEGA](https://pokecahack.com/ar/)、[SV](https://pokecahack.com/ar/2/#sv)、[S12a](https://pokecahack.com/ar/3/#s)
- CHR：[収録弾別一覧](https://pokecahack.com/csr-chr/)
- 照合：[TCGdex/cards-database](https://github.com/tcgdex/cards-database)
- 英語名対応：[PokeAPIのポケモン名](https://github.com/PokeAPI/pokeapi/blob/master/data/v2/csv/pokemon_species_names.csv)

参考画像はカード単体です。実際のPSA商品画像とは区別して表示します。

## 成約データ

ALTの商品ページの公開 `Recent transactions` 欄に表示される成約日・USD価格・取引元・取引方法を読みます。eBayやFanatics Collect等の取引をALT自社の成約とは混同しません。

- Lowest price、現在の入札額、出品価格、PSA人口は成約価格に含めません。
- 公開欄の最大4件程度を取得し、以前に確認した履歴も保持します。全取引履歴の網羅ではありません。
- 商品名、番号、日本語版、AR/CHR、選択されたPSAグレードを照合します。ARとSAR、CHRとCSRを区別します。
- PSAグレード切替後も元のヘッダー・画像が残る場合があります。価格は選択中のグレードの履歴を読み、画像のグレードが一致しなければ画像を出しません。
- 明確な履歴なし表示のみ `no_sales` とします。読み込み失敗や未照合は `pending` / `error` と区別します。
- 送料・税・ベストオファーの内訳、同日の取引時刻は確認していません。

## GitHubでの公開・更新

このフォルダを専用リポジトリのルートへ登録します。既存アプリへの参照はありません。
GitHub Pagesの「Deploy from a branch」でmain・/(root)を選ぶと、ルートのindex.htmlから開けます。
成約データ・カード一覧・更新状況は同じサイトのdist/内から読みます。

毎日11時ごろ（日本時間）の定期タスクが、この専用リポジトリ M0CH4771/tck-card-sales のmainに確認済みデータを保存します。
取得方法はChatGPTの定期タスクによるALT公開画面の確認です。リポジトリだけで自動取得が始まるわけではありません。
「最新データを表示」は取得済みデータの再読込であり、ALTの即時再取得ではありません。
未確認の商品も取得対象に含め、確認日時が古い順に調べ、失敗した商品の前回履歴と日時を保持します。

初期データはPSA8を192種類確認し、182種類に成約履歴、10種類に明確な公開履歴なし表示を確認しています。
残り413種類のPSA8価格は未確認です。既存のユキワラシPSA9を含め597件の成約履歴を保存しています。

## 機能と構成

- 日本語／英語名、ひらがな／カタカナ、全角型番、複数キーワード検索
- PSAグレード、AR/CHR、収録弾、価格の確認状況、取引元の絞り込み
- 成約日・価格・名前順。50件ずつ追加表示、スマートフォンの詳細移動
- 履歴CSV出力、CSV/JSONの一時読み込み。検索条件をURLに保持
- `dist/`：公開サイト、カード一覧、成約履歴、更新状況
- `scripts/targets.json`：全種類の取得対象と照合済みURL候補
- `scripts/parse-alt.mjs`：公開行の解析とグレード等の検証
- `scripts/merge-observations.mjs`：検証済み履歴を部分更新し、前回履歴を保持

Node.js 22以降で `npm test`。追加依存なし。件数・収録弾・未確認価格・PSA分離・レアリティ・CSV・部分更新を検証します。ブラウザによる画面QAとWebMCPの実行検証はこの変更では行っていません。

データの変更もGitHub Pagesから配信されます。共有JSONを読めないときは同梱または直前のデータを表示し、最新情報を確認できない旨を示します。
